What the Holoplayer Accuracy Mod does

The mod sends exact mouse and key timing only during rounds you agreed to record, through your normal Minecraft connection. This makes your holoplayer copy you more closely.

Data protection: To keep the training data clean, the mod also sends the server the list of your installed mods and a check that the mod itself hasn't been changed. This is only used to detect cheating, tampering with the data, and mods that aren't allowed on the server (such as combat recorders). From version 1.4.0 the list includes a SHA-512 fingerprint of each mod file, the same code Modrinth uses to identify a mod version. The files themselves are never uploaded, and nothing else on your computer is read.
